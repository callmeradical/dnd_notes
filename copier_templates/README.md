# Copier Templates

This directory contains [Copier](https://copier.readthedocs.io/) templates that help generate new content for the notes site.

## New Blog Post or Note

```
copier copy copier_templates/post docs/blog/posts
```

You will be prompted for the post information. The new file will be created in `docs/blog/posts/` with the name you provide.
Use this template to record session notes and other updates; campaigns are no longer tracked separately.

## Session Prep Template

```
copier copy copier_templates/session_prep docs/planning
```

Creates a structured session prep template with:
- Strong start opening
- 5 planned scenes with key elements checklists
- Space for up to 3 key NPCs with details
- Session notes and follow-up sections

You'll be prompted for campaign name, session number, scene descriptions, and NPC details.
