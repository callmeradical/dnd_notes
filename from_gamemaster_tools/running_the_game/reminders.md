* Make one of the players an official rules lawyer, with the responsibility for looking up rules questions when they arise.
* Improvise ability and skill checks by choosing DCs during play, or ask for a check and describe the result based on the roll without matching it to a specific DC.
* Ask all the players to help adjudicate particular rulings, and go with their results whenever you can.

The following ideas were taken from [Dungeon World DMing](https://www.dungeonworldsrd.com/gamemastering/)

| Agenda                                    | Principles                              | Moves                                              |
|-------------------------------------------|-----------------------------------------|----------------------------------------------------|
| Portray a fantastic world                 | Draw maps, leave blanks                 | Use a monster, danger, or location move            |
| Fill the characters’ lives with adventure | Address the characters, not the players | Reveal an unwelcome truth                          |
| Play to find out what happens             | Embrace the fantastic                   | Show signs of an approaching threat                |
|                                           | Make a move that follows                | Deal damage                                        |
|                                           | Never speak the name of your move       | Use up their resources                             |
|                                           | Give every monster life                 | Turn their move back on them                       |
|                                           | Name every person                       | Separate them                                      |
|                                           | Ask questions and use the answers       | Give an opportunity that fits a class’ abilities   |
|                                           | Be a fan of the characters              | Show a downside to their class, race, or equipment |
|                                           | Think dangerous                         | Offer an opportunity, with or without cost         |
|                                           | Begin and end with the fiction          | Put someone in a spot                              |
|                                           | Think offscreen, too                    | Tell them the requirements or consequences and ask |
