# NPC Statblock Template

## Basic Template

```markdown
## [NPC Name]

**Size Type, Alignment**  
**Armor Class** X (Natural Armor/Armor Type)  
**Hit Points** X (XdY + Z)  
**Speed** X ft.

| STR | DEX | CON | INT | WIS | CHA |
|-----|-----|-----|-----|-----|-----|
| X(+X) | X(+X) | X(+X) | X(+X) | X(+X) | X(+X) |

**Saving Throws** Stat +X, Stat +X  
**Skills** Skill +X, Skill +X  
**Damage Resistances/Immunities** Type  
**Condition Immunities** Condition  
**Senses** Darkvision 60 ft., Passive Perception X  
**Languages** Common, Other  
**Challenge** X (X XP)  
**Proficiency Bonus** +X

### Features

**Feature Name.** Description of feature.

### Actions

**Multiattack.** The [NPC] makes X attacks.

**Attack Name.** *Melee/Ranged Weapon Attack:* +X to hit, reach X ft./range X/X ft., one target. *Hit:* X (XdY + Z) damage type damage.

### Bonus Actions

**Bonus Action Name.** Description.

### Reactions

**Reaction Name.** Description.

### Legendary Actions (if applicable)
*The [NPC] can take 3 legendary actions, choosing from the options below. Only one legendary action option can be used at a time and only at the end of another creature's turn. The [NPC] regains spent legendary actions at the start of its turn.*

**Action Name.** Description.
**Action Name (Costs 2 Actions).** Description.

---

### Roleplay Information

**Personality Traits**
- Trait 1
- Trait 2

**Ideals**
- Ideal 1: Description

**Bonds**
- Bond 1: Description

**Flaws**
- Flaw 1: Description

**Mannerisms**
- Physical quirk or speech pattern
- Behavioral tendency

**Tactics**
- Combat approach
- Preferred strategies
- Retreat conditions
```

## Simplified Social NPC Template

```markdown
## [NPC Name]

**Role/Title:** Description  
**Race:** Race, **Class:** Class Level (if applicable)  
**Armor Class** X, **Hit Points** X, **Speed** X ft.

**Key Stats:** STR +X, DEX +X, CON +X, INT +X, WIS +X, CHA +X  
**Notable Skills:** Skill +X, Skill +X  
**Challenge Rating:** X

### Roleplay

**Personality:** Brief description of demeanor and attitude  
**Motivation:** What drives them  
**Secret/Hook:** Hidden information or plot connection  

**Voice/Mannerisms:** How they speak and act  
**Knowledge:** What they know that's useful to PCs  

### Key Stats Only
- **Passive Perception:** X
- **Passive Insight:** X  
- **Key Save DCs:** Spell Save DC X, etc.
```

## Monster/Combat NPC Template

```markdown
## [Creature Name]
*Size type, alignment*

**AC** X **HP** X (XdY+Z) **Speed** X ft.

**STR** X(+X) **DEX** X(+X) **CON** X(+X) **INT** X(+X) **WIS** X(+X) **CHA** X(+X)

**Skills** Skill +X  
**Senses** Sense X ft., passive Perception X  
**Languages** Languages  
**CR** X (X XP) **PB** +X

### Actions
**Attack.** *Melee Weapon Attack:* +X to hit, reach X ft., one target. *Hit:* X (XdY+Z) type damage.

### Tactics
- Combat behavior
- Preferred targets
- Environmental usage
```

## Usage Examples

### Example: Social NPC
```markdown
## Merchant Kira Brightcoin

**Role/Title:** Traveling Merchant & Information Broker  
**Race:** Halfling, **Class:** Rogue 5  
**Armor Class** 14, **Hit Points** 32, **Speed** 25 ft.

**Key Stats:** STR -1, DEX +3, CON +1, INT +2, WIS +1, CHA +2  
**Notable Skills:** Deception +5, Insight +4, Persuasion +5  
**Challenge Rating:** 2

### Roleplay

**Personality:** Cheerful and talkative, but always calculating profit margins  
**Motivation:** Accumulate wealth and expand her trading network  
**Secret/Hook:** Secretly fences stolen goods for the Boromar Clan  

**Voice/Mannerisms:** Rapid speech with merchant cant, constantly counting coins  
**Knowledge:** Trade routes, local politics, who's buying what where  

### Key Stats Only
- **Passive Perception:** 14
- **Passive Insight:** 14
- **Sneak Attack:** 3d6
```

---

**Usage Tips:**
- Copy the appropriate template section to your NPC notes
- Fill in only the stats you need for your encounter
- For social NPCs, focus on roleplay information
- For combat NPCs, prioritize mechanical details
- Use the simplified template for minor NPCs
- Always include at least one interesting trait or secret
