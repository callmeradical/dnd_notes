### Naming & Filing Guidelines
1. **Choose the closest category** before creating a new note. If none apply, add a new subheading here and update navigation in `mkdocs.yml`.
2. **Use descriptive filenames** (`Topic - Descriptor.md`) and begin content with `# Title`.
3. **Cross-link** to related notes using relative Markdown links (e.g., `[Nagano](Nagano.md)`).
4. **Add summary bullets** or tables in top-level notes to help surface key hooks, NPCs, or encounters quickly.

Maintaining this taxonomy keeps the campaign wiki navigable as the archive grows.
