## Frontmatter Format Used

All session notes use this consistent YAML frontmatter:

```yaml
---
title: "Session NNN: [Title]"
session_number: NNN
arc: "Arc N - [Arc Title]"
date_played: "YYYY-MM-DD"
campaign: "The Last Whisper of Steel"
tags:
  - session-log
  - tlw
  - arc-N
  - [other relevant tags]
---
```

## Template for Creating Sessions 000-017

Each session should include:

1. **Frontmatter** (YAML format)
2. **Session Summary** (paragraph overview)
3. **Key Events** (chronological breakdown)
4. **NPCs Encountered** (with roles and status)
5. **Locations Visited** (with descriptions)
6. **Active Quests** (primary, secondary, urgent)
7. **Plot Threads & Mysteries** (ongoing questions)
8. **Key Quotes** (memorable dialogue)
9. **Character Development** (per PC)
10. **Items & Rewards** (loot and treasure)
11. **Experience Points** (XP breakdown)
12. **GM Notes** (what worked, what to improve)
13. **Next Session Preparation** (prep checklist)
14. **Campaign Connections** (how it ties to larger story)
