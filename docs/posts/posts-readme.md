## Frontmatter Format

All session notes should use this YAML frontmatter format:

```yaml
---
title: "Session NNN: [Title]"
session_number: NNN
arc: "Arc N - [Arc Title]"
date_played: "YYYY-MM-DD"
campaign: "The Last Whisper of Steel"
tags:
  - session-log
  - tlwos
  - arc-N
  - [other relevant tags]
---
```
