# Writing Systems and Record-Keeping in Shuigari

## Overview

Shuigari's written language evolved from ancient mainland scripts, adapting over centuries into distinct forms that serve different social and functional purposes. The writing system reflects the civilization's values: hierarchy, tradition, artistic expression, and practical administration. Multiple script forms coexist, each carrying social and contextual significance.

## The Three Script Systems

### Kaisho (楷書) - Standard Block Script

**Characteristics:**
- Clear, angular characters
- Each stroke deliberate and separated
- Approximately 2,500 common characters
- Additional 3,000+ specialized/rare characters
- Takes 8-12 years to achieve literacy

**Usage:**
- Official documents and decrees
- Legal contracts and records
- Temple inscriptions
- Formal education
- Published books
- Permanent records

**Social Significance:**
- Mastery indicates education and status
- Calligraphy quality matters (beautiful writing = noble character)
- Test of literacy uses Kaisho exclusively
- Samurai expected to write Kaisho elegantly

**Character Types:**

*Ideographic (Meaning-based)*
- Characters represent concepts/objects
- Example: 剣 (sword), 山 (mountain), 火 (fire)
- Most complex characters (8-20+ strokes)

*Phonetic Elements*
- Some characters indicate pronunciation
- Combined with meaning characters
- Helps read unfamiliar words

*Compound Characters*
- Combine multiple elements
- Example: 鍛 (forging) = metal + section + fire
- Technical vocabulary often compounds

### Gyosho (行書) - Running Script

**Characteristics:**
- Flowing, connected strokes
- Faster to write than Kaisho
- More cursive but still readable
- Abbreviates some strokes
- Individual style variation allowed

**Usage:**
- Personal letters
- Business correspondence
- Quick notes and records
- Poetry composition
- Diplomatic messages
- Daily documentation

**Social Significance:**
- Standard for literate adults
- Shows education without pretension
- Personality visible in handwriting
- "Reading" someone's character through writing

**Variations:**
- Scholar's Gyosho: More controlled, elegant
- Merchant's Gyosho: Quick, efficient
- Military Gyosho: Clear, standardized

### Sosho (草書) - Grass Script

**Characteristics:**
- Highly cursive and artistic
- Strokes flow into each other
- Difficult to read without training
- Each calligrapher develops unique style
- "Abbreviated" characters barely recognizable

**Usage:**
- Artistic calligraphy
- Poetry (especially on scrolls)
- Personal journals and diaries
- Secret communications
- Seal scripts and signatures

**Social Significance:**
- Mark of high cultivation
- Appreciation requires education
- Collectors value famous calligraphers
- Some Sosho incomprehensible without context

**Challenges:**
- Same character may look completely different
- Context essential for reading
- Learning Sosho takes years after mastering Kaisho
- Some scholars specialize in deciphering old Sosho texts

## Supplementary Scripts

### Kana - Syllabic Script

**Two Forms:**

*Hiragana (平仮名)*
- Simplified, flowing characters
- 46 basic syllables + combinations
- Derived from cursive Kaisho
- Used for:
  - Grammatical particles
  - Native words without Kaisho
  - Children's writing
  - Informal notes
  - Phonetic guides (furigana) above complex Kaisho

*Katakana (片仮名)*
- Angular, simplified characters
- Also 46 basic syllables
- Derived from Kaisho fragments
- Used for:
  - Foreign words (rare in Shuigari)
  - Emphasis
  - Technical/scientific terms
  - Telegraphic-style shorthand

**Learning Curve:**
- Children learn Kana first (ages 6-8)
- Can read simple texts with Kana only
- Then transition to Kaisho (ages 8+)
- Literate adults use mixed script (Kaisho + Hiragana)

**Social Implications:**
- Kana-only writing seems childish or uneducated
- "Women's writing" stereotype (educated women also use Kaisho)
- Practical for those with limited education
- Some poetry deliberately uses Kana for effect

### Runic Scripts (Reitō 霊刀)

**Characteristics:**
- Ancient characters predating current scripts
- Approximately 200 core runes
- Each rune represents spiritual concept
- Often combined in patterns

**Usage:**
- Magical inscriptions
- Protective talismans
- Shrine and temple decorations
- Sealing rituals
- Weapon enchantments
- Divination

**Who Learns:**
- Onmyoji (required study)
- Shrine priests and priestesses
- Some samurai (spiritual warriors)
- Ninja (for certain techniques)
- Forbidden to commoners

**Spiritual Properties:**
- Believers claim runes have inherent power
- Proper calligraphy essential for magic to work
- Mistakes in runic writing dangerous
- Some runes "locked" (only certain people can use)

**Rune Categories:**

*Elemental Runes*
- Fire, Water, Earth, Air, Void
- Foundation of most magical work

*Protection Runes*
- Ward against evil spirits
- Bind demons
- Protect spaces/objects

*Binding Runes*
- Seal magical items
- Create contracts with spirits
- Contain dangerous forces

*Divination Runes*
- Cast to read fortunes
- Interpret kami will
- Predict events

### Cipher Scripts

**Military Ciphers:**
- Each domain has own code
- Based on Kaisho with substitution
- Changed periodically
- Officers memorize cipher key
- Captured messages useless without key

**Ninja Clan Scripts:**
- Unique to each clan
- Combination substitution and symbol modification
- Some use deliberately bad calligraphy as code
- Messages appear to be meaningless scribbles
- Decryption requires clan training

**Merchant Guild Codes:**
- Shorthand for trade goods
- Numerical ciphers for prices
- Symbols for quality grades
- Protect proprietary information

**Criminal Argot:**
- Thieves' cant uses modified Kana
- Symbol system overlaid on normal text
- Hidden messages in innocent-looking letters
- Law enforcement learns common criminal codes

## Calligraphy as Art

### The Four Treasures of the Study

**Brush (Fude 筆)**
- Made from animal hair (rabbit, wolf, weasel)
- Quality: 50 mon (poor) to 20 ryo (master-crafted)
- Craftsmen specialize by hair type and size
- Samurai often own multiple brushes
- Famous calligraphers' brushes become relics

**Ink (Sumi 墨)**
- Solid ink sticks ground with water
- Made from pine soot and animal glue
- Quality affects color and permanence
- Cost: 100 mon (common) to 10 ryo (finest)
- Aged ink prized by experts
- Grinding ink is meditative preparation

**Paper (Washi 和紙)**
- Handmade from plant fibers
- Different weights and textures
- Absorbs ink beautifully
- Cost: 200 mon/ream (common) to 5 ryo/ream (finest)
- Quality paper lasts centuries
- Some papers have embedded flowers, gold flakes

**Inkstone (Suzuri 硯)**
- Stone slab for grinding ink
- Slate or jade
- Well for water, flat surface for grinding
- Cost: 500 mon (plain) to 50 ryo (carved jade)
- Heirloom inkstones passed down generations
- Some believe stone quality affects ink spiritual properties

### Calligraphy Schools

**Major Styles:**

*Tensho School (天書流)*
- Founded 300 years ago
- Emphasizes spiritual dimension
- Each character should embody its meaning
- Students meditate before writing
- Headquarters: Hikosan temple

*Genji School (源氏流)*
- Founded by legendary warrior-poet
- Combines martial precision with artistic flow
- Popular among samurai
- Teaches "sword in brush" philosophy
- Headquarters: Takashima

*Flowing River School (流水流)*
- Merchant class friendly
- Emphasizes clarity and efficiency
- Beautiful but practical
- Most common in commercial settings
- Multiple branches in cities

**Training:**
- Apprentice (3-5 years): Copy masters' work exactly
- Journeyman (3-5 years): Develop understanding of principles
- Master (lifetime): Achieve personal style while respecting tradition

**Social Role:**
- Calligraphy skill essential for social advancement
- New Year's first calligraphy (kakizome) important ritual
- Calligraphy competitions at festivals
- Famous calligraphers can earn 20-50 ryo annually
- Nobles commission calligraphy for special occasions

## Numbers and Mathematics

### Number Writing

**Standard Numerals (Kanji):**
```
一 (1) 二 (2) 三 (3) 四 (4) 五 (5)
六 (6) 七 (7) 八 (8) 九 (9) 十 (10)
百 (100) 千 (1,000) 万 (10,000)
```

**Financial Numerals (Daiji):**
- Complex forms prevent alteration
- Used in contracts, tax records, receipts
- Example: 壱 instead of 一, 弐 instead of 二
- Harder to change 壱 to 弐 than 一 to 二

**Counting Systems:**
- Different counters for different objects
- People, animals, flat objects, long objects each counted differently
- Shows education level to use correctly

### Abacus (Soroban 算盤)

**Tool:**
- Wooden frame with beads on rods
- Upper beads = 5, lower beads = 1
- Can calculate complex math quickly
- Cost: 500 mon (basic) to 3 ryo (fine crafted)

**Usage:**
- Merchants use daily
- Accountants essential tool
- Some schools teach abacus
- Mental abacus (imaginary soroban) practiced by experts

**Cultural Role:**
- Merchant class mastery
- Samurai sometimes disdain (too mercantile)
- But military logistics requires math
- Competitions for fastest calculation

### Written Mathematics

**Notation:**
- Problems written in Kaisho with numerals
- Results recorded precisely
- Complex calculations shown step-by-step
- Accounting books use standard formats

**Advanced Math:**
- Geometry for architecture/engineering
- Astronomy calculations for calendar
- Military: Range, trajectory, supply calculations
- Some samurai academies teach advanced math
- Treatises on mathematics exist (rare, expensive)

## Record-Keeping Systems

### Government Records

**Domain Archives:**

*Tax Records (Zeimucho 税務帳)*
- Village-by-village rice production
- Individual family obligations
- Payment history
- Arrears and penalties
- Updated annually
- Permanent record (stored indefinitely)

*Land Surveys (Kenchi-cho 検地帳)*
- Detailed field measurements
- Productivity ratings
- Ownership/usage rights
- Updated every 10-20 years
- Legal authority for tax assessment

*Population Registers (Ninbetsu-aratame-cho 人別改帳)*
- Every household registered
- Names, ages, relationships
- Occupations
- Temple affiliations
- Updated annually
- Controls population movement

*Samurai Rolls (Bukan 武鑑)*
- Complete list of samurai retainers
- Ranks and stipends
- Family lineages
- Service records
- Updated when changes occur

**Organization:**
- Dedicated clerical staff (20-100 per domain)
- Organized by location and date
- Cross-referenced for verification
- Stored in fireproof warehouses
- Multiple copies for important records

### Commercial Records

**Merchant Account Books:**

*Daily Ledger (Hidzuke-cho 日付帳)*
- All transactions recorded
- Date, item, quantity, price, customer
- Updated daily
- Kept for 7-10 years

*Customer Credit Book (Kakeuri-cho 掛売帳)*
- Who owes money
- Amount and date
- Payment schedule
- Interest calculations

*Inventory Records (Zaiko-cho 在庫帳)*
- Goods on hand
- Location in warehouse
- Condition notes
- Updated monthly (or more often)

*Contract File (Keiyaku-sho 契約書)*
- All agreements
- With seals and witnesses
- Permanent records
- Referenced in disputes

**Merchant Guild Requirements:**
- Members must maintain proper books
- Guild audits periodically
- Fraudulent records = expulsion
- Some guilds standardize formats

### Temple Records

**Types:**

*Ritual Calendars*
- Festival dates
- Ceremonies performed
- Offerings received
- Attendance records

*Congregation Lists*
- Registered members
- Family temples (danka system)
- Births, deaths, marriages
- Serves as vital records

*Donation Records*
- Who gave what
- Date and purpose
- Public acknowledgment
- Tax implications

*Sacred Texts*
- Sutra copying
- Commentary and interpretation
- Historical documents
- Carefully preserved

**Preservation:**
- Monks copy deteriorating texts
- Fire-resistant storage
- Some temples have libraries open to scholars
- Ancient records sometimes reveal forgotten history

### Personal Records

**Family Records:**

*Genealogy (Kafu 家譜)*
- Family tree going back generations
- Samurai families especially detailed
- Proves lineage and inheritance rights
- Updated at births, deaths, marriages

*Household Accounts*
- Income and expenses
- Samurai families track stipend usage
- Merchant families track business
- Helps plan for future

**Personal Diaries:**
- Private journals common among literate
- Events, thoughts, poetry
- Some become historical sources
- Famous diaries published after death

## Literacy and Documentation Practices

### Who Writes What

**Samurai:**
- Personal correspondence
- Poetry
- Military reports
- Administrative documents
- Journals/diaries

**Merchants:**
- Account books
- Contracts
- Business letters
- Invoices and receipts
- Guild documents

**Priests/Monks:**
- Religious texts
- Ritual records
- Temple administration
- Copying sutras
- Scholarly works

**Professional Scribes:**
- Hired by illiterate or semi-literate
- Write formal documents
- Copy texts
- Create official records
- Cost: 20 mon (simple letter) to 5 shu (complex legal document)

**Specialists:**
- Calligraphers (artistic work)
- Copyists (replicate texts)
- Seal carvers (create official seals)
- Account keepers (financial records)

### Document Authentication

**Personal Seals (Hanko 判子):**
- Carved stone or wood
- Unique to individual
- Stamp in red ink
- Legal signature
- Registered with authorities
- Cost: 200 mon (simple) to 10 ryo (jade carved by master)

**Official Seals:**
- Government offices have official seals
- Multiple levels (village, domain, Shogunate)
- Counterfeiting seals = death penalty
- Wax seals for securing documents

**Witnesses:**
- Important documents require 2-3 witness seals
- Witnesses legally liable for content
- Usually respected community members

**Dating:**
- Era name + year + month + day
- Example: "Tensho Era, Year 5, 3rd Month, 15th Day"
- Era changes with new emperor or major events

### Archival Practices

**Storage:**
- Fireproof warehouses (stone/earthen walls)
- Documents wrapped in silk
- Cedar boxes resist insects
- Climate controlled when possible
- Multiple copies of crucial records

**Organization:**
- Chronological filing common
- Subject matter categories
- Cross-reference systems
- Catalogs of holdings
- Professional archivists (paid 3-8 shu monthly)

**Access:**
- Government archives: Officials only
- Temple archives: Scholars with permission
- Merchant archives: Guild members only
- Family archives: Family members only

**Preservation:**
- Recopying deteriorating documents
- Some records recopied every 50-100 years
- Original vs. copy indicated clearly
- Authentication of copies important

## Regional Variations

### Takashima Prefecture
- Strong emphasis on technical documentation
- Metallurgy manuals closely guarded
- Mining records extremely detailed
- Practical writing valued over artistic

### Hikosan (Capital)
- Highest literacy rates
- Most formal/traditional writing
- Archive of all Shogunate records
- Center of calligraphy culture

### Port Cities
- Simplified merchant scripts
- Foreign loanwords appear
- Quick, efficient writing style
- Less concern for artistic beauty

### Rural Areas
- Limited literacy
- Village headman keeps official records
- Oral tradition still primary
- Religious texts main written materials

## Current Trends

### Woodblock Printing
- Making books more affordable
- Popular works widely distributed
- Some opposition (devalues hand-copying)
- Print shops in major cities
- New profession: Type setters

### Standardization Efforts
- Shogunate promoting unified formats
- Tax records becoming standardized
- Resistance from traditional domains
- Benefits: Easier comparison and auditing

### Rising Literacy
- More terakoya schools
- Merchant class increasingly literate
- Women's literacy growing (slowly)
- Threatens traditional social order
